# 公开体验核验 · 2026-10-31

正式入口：https://yaowenhu.cn/teamlink-demo/ 。由独立公开仓库的静态GitHub Pages发布，不修改个人主页内容，不接入团队服务或凭据。

- 状态模型9项测试通过：两个场景的完整往返、角色与版本约束、不可变记录、具体退回和逐项验收、存档恢复及篡改拒绝。
- 桌面浏览器真实操作：确认→接单→检查失败阻止交付→通过样例→提交→发现导出超时清空筛选→具体退回AC2→新示例提交→补交→筛选保留→下载CSV→逐项验收。
- 下载样例实际含本月“产品”两条数据，没有原始需求输入。
- 手机尺寸390×844真实浏览器操作：登录场景首轮取消后错误返回首页，退回AC3并补交后取消保留原活动；无横向溢出。首次未整理输入在角色切换后保留。
- 公开网址不带账号、令牌或Cookie的HTTP读取返回200；GitHub仓库、README及其CI均可公开读取。
- 标准二维码编码同一公开URL；微信/飞书实机客户端扫码未执行，不能以浏览器尺寸模拟替代。

本体验是明确标注的虚构角色、确定规则和本地小功能样例，不是实时大模型、实际CI、真实多人接单或业务验收。页面输入保留在浏览器会话，静态站不收集上传。
