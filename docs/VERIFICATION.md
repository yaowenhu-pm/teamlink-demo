# TeamLink v0.3 验证 · 2026-10-31

入口：[公开工作区](https://yaowenhu.cn/teamlink-demo/)。本轮参考 GatherThread 官网、公开示例和固定提交源码，保留直接编辑模型，加入项目语境、方案、批注和外部 Agent 提案交接。

## 本地与浏览器实测

| 路径 | 观察到的结果 |
| --- | --- |
| 直接修改规则 | 切换保留筛选，选择→请求→文件从3→10→10变为3→3→3；同屏结果文件随之更新 |
| 命名方案 | 原版快照保持10条，修改后可把它设为对照；验证轨迹显示原版条件和10条文件；恢复原版后重新得到10条 |
| 关联批注 | 保存规则问题时冻结当时作品；网页导出的真实Agent任务包包含该批注和完整基准作品 |
| 外部Agent往返 | 独立Codex子代理读取实际任务数据，返回两条规则修改的JSON；浏览器导入后显示10→3行、三项不符→零项不符，预览前未改动当前作品 |
| 冲突拦截 | 导入提案后另改作品标题，提案立即显示旧基准冲突并禁用采纳；撤销该改动后才能采纳 |
| 采纳与下载 | 采纳后保留筛选与原条件重试生效；实际下载CSV为3条2026年10月产品记录，UTF-8及CRLF内容核对通过 |
| 项目包 | 浏览器下载包含方案、批注、活动和作品的完整包；在分享副本中导入后恢复1份命名方案和1条批注 |
| 手机直接编辑 | 390×844下修改标题和记录内容，终态文件预览包含新内容，页面宽度仍为390；数据表内部横向滚动 |
| 副本隔离 | 接收者修改手机副本后，原作者本地作品标题和数据未被覆盖；普通分享链接不携带本地批注和方案 |

## 验证边界

Agent往返是本次真实外部子代理工作，候选JSON只用于QA，没有把回答作为公开页面的预置AI结果。网页本身没有调用模型、运行后台Agent或连接真实导出服务。所有效果比较仍是明确计算假设下的结果，不等于生产性能、代码CI或真实业务验收。

没有测试真人同时编辑、真实微信／飞书客户端扫码或真实中文输入法物理按键。当前没有同房间多人同步、成员认证或平台自动写入。浏览器模拟手机只证明对应视口的布局和网页交互。

部署验收需检查无需登录的公开访问、静态资源与本地散列一致，并从公开页面实际编辑。历史版本已通过的发布检查不代替本轮检查。

## v0.2 历史验证


当前入口：https://yaowenhu.cn/teamlink-demo/ 。原顺序交接演示由共创画布替换，原实现可从Git历史恢复。

## 本地已观察

- 改标题即时进入文档，保留的对照不跟随修改。规则改动直接驱动请求与文件：默认10行，保留筛选后3行；只修改重试来源时文件正确、输入仍不同。
- 等待预算改为1080ms后，首次1080ms内完成，重试分支消失。修改月份、分类、数据与金额会重算实际文件。
- 实际下载CSV含访客编辑的“设计研究／现场长出的新想法／99.5”，有真实CRLF与UTF8内容，非屏幕假结果。
- 分享链接在新标签页恢复相同标题、规则、分类、数据与计算结果；接收者修改副本后，原本地文档存档保持不变。
- 编辑时可撤销和重做；无效日期后删除该行，表格实际移除并恢复有效状态。
- 390×844浏览器无横向溢出；底部实时结果摘要在编辑规则时保留。真实微信、飞书客户端实扫及真实中文输入法物理按键未执行。

纯模型测试覆盖实际因果、预算边界、两次失败无文件、空结果表头、任意有效月份/分类、文案与数据、CSV转义、Unicode分享恢复与结构/大小限制。浏览器检查不把计算耗时当成真实网络测速，也不把分享副本称为多用户同步。

发布后须核对公开HTML/模块与当前源文件一致，以及无需登录的访问和实际编辑。此前版本的公开读取与CI成功，不替代本版结果。
