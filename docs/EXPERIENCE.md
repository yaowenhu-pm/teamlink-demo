# 用直接修改来探索产品

打开即可编辑和运行，没有角色切换或步骤解锁。作品包括可编辑文案、结构化行为规则、数据与判断期望；界面、过程、情境核对和CSV都读取同一份文档。

## 一次可以产生发现的尝试

1. 先“保留这一版作对照”，再切换保留筛选规则。整个过程同时改变，保留的版本不跟随修改。
2. 关闭保留筛选，只让重试沿用第一次条件。查看界面与文件的差异，发现两种承诺并不相同。
3. 直接拖动超时预算，看看哪些状态会出现或消失。展开耗时假设，修改首次或重试网络倍数；两次都超时时确实不会生成文件。
4. 改数据、分类、月份或金额，再下载CSV。输出包含的就是当前模型实际计算出的行。
5. 判断期望也可以修改。界面用实际值与期望比较，不把文字描述自动当成行为规则。

点击四段轨迹能回到相应时刻；时间条可以往返。进入编辑时暂停回放，防止正在编辑的状态随时间改变。

## 保留、恢复与继续共创

撤销与重做针对作品编辑；回放不改变作品。对照保存独立快照，更新或移除须显式操作。作品和对照保留在当前浏览器，浏览器禁止保存时仍可导出JSON。

“分享作品”链接的片段携带当前文档，不上传文档到服务器；打开的人编辑独立副本，不覆盖原作者。二维码只打开默认作品。JSON可以导入并继续编辑。文档有大小和结构限制；无效文件不会执行为代码或覆盖有效作品。

没有同一房间的多设备实时同步、线上光标或自动合并。需要这些能力时应增加服务端文档与冲突协议，不能把链接分享称为已实现的多人共同编辑。

## 计算与真实服务

耗时公式是“（基础耗时＋条数×每条耗时）×网络倍数”；首次与重试应用相同公式、使用各自明示的倍数。它不是测速结果，不会发出真实导出请求。CSV在浏览器内实际生成，字符串按CSV规范转义并避免被表格软件当公式执行。

文案、数据均为可编辑内容，模型不会推断任意自然语言的含义；实际产品实现与验收仍需在真实环境完成。
