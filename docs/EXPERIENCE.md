# 体验说明

本页让陌生访客直接体验一次需求到验收的交接。无需安装 Codex、注册或连接企业账号；小林、小周、飞书视图、Issue、PR、检查结果及提交版本全部是虚构样例。

## 一轮完整交接

1. **产品确认**：选择场景或改写需求，点击“整理交接单”，核对标题与验收标准，再确认交接。整理使用固定示例规则，可手动修改。
2. **研发接单与交付**：小周接下所见版本；可查看通过或失败的检查样例。只有通过样例后明确提交，才进入待验收。没有实际运行代码或 CI。
3. **体验并退回**：在“体验功能”中亲手操作首轮样例，选择未达到的条目并写明问题。退回原因与前一轮交付会保留。
4. **补交与验收**：回到研发视角查看补交检查样例并补交；产品重新体验、逐项勾选，再记录本次演示验收。
5. **尝试变更**：完成后可修改需求草稿。确认新版后，需要重新接单、提交和验收；旧记录保留。

“导出失败重试”的首轮问题是超时后筛选条件被清空；补交样例会保留条件。成功后可下载浏览器生成的 CSV 样例，用于核对选中数据；这里没有真实 Excel 导出服务。

“登录后回原页”的首轮问题是取消登录后落到无关首页；补交样例会保留原活动。登录成功、失败和取消都是本地模拟，没有真实登录。

自定义需求只能体验内容整理和交接规则，不会实时理解业务、生成代码或提供与该需求对应的功能产物。请先用预设场景完成首轮体验。

## 数据与身份边界

- 角色切换让一位访客扮演双方，不代表真人登录、在线、接单或验收。
- 正文与进度保存在当前标签页的 `sessionStorage`。刷新可以恢复任务；示例小组件的临时操作和验收勾选不作为长期记录。
- 换浏览器、设备或重新打开入口不会自动接续另一处进度；“重新体验”重置当前任务。浏览器禁止存储时，页面仍可操作，但无法保存会话。
- 页面不上传访客输入，不调用业务后端、实时 LLM、飞书或 GitHub API，也没有分析埋点。浏览器仍需加载本站静态资源。
- 飞书与 GitHub 页签只展示示例投影，不会创建文档、Issue、PR 或通知任何人。示例下载不含访客需求内容。
