# TeamLink

一片可以一起修改的风景。拖动对象、画出落叶路线，或说一句话，让想法变成眼前的变化。

**[在线体验](https://teamlink.yaowenhu.cn/) · [手势实验](https://teamlink.yaowenhu.cn/gesture/)**

## 三步体验

无需安装或登录。

1. 打开网页，拖动太阳，或点击“画落叶路线”画一笔，松手保存。
2. 扫描画布旁的二维码，用手机进入同一个房间。
3. 输入“增加两艘船，下点小雨”，同伴的页面会同步变化。

还支持对象复制、剪切、粘贴、删除、撤销与重做，参数与源码对照、恢复默认、全屏和背景音乐。画布内按 `?` 查看快捷键。

## 首页手势共创

在主画布点击 **手势控制 → 开启摄像头**，允许权限后：

- 张开手靠近树、山、船或鸟，捏合移动，松开同步。
- 比 **V** 保持半秒打开菜单，再张开手，停留选择对象、复制、剪切、粘贴、删除、撤销或重做。
- 粘贴时移动手掌预览，捏合并松开放下；丢手或 `Esc` 取消，不保存未完成的修改。
- 伸出食指、中指、无名指约 0.6 秒，切换自动拾取／手动固定；也可在菜单切换。
- 菜单还可调整时间、风雨、数量、树形，或手绘落叶路线。原有鼠标、对话、扫码、音乐和全屏继续使用。

首页手势与鼠标共用同一房间和剪贴板；松手确认后，其他页面会同步。键盘 `V` 打开手势菜单，`T` 切换选择模式；其他快捷键见画布内 `?`。

相机画面只在本机识别，不上传；首次准备约 10 MB，之后通常复用缓存。真人摄像头的光照与手感仍需体验者实际测试。

## 独立手势实验

推荐电脑 Chrome 或 Edge。开启摄像头并允许权限后：

- 抬手靠近物体，捏合拇指和食指移动，松开保存。
- 伸出食指、中指和无名指，小指弯曲、拇指张开，保持约 **0.6 秒**切换自动／手动选择。手动时固定对象；没有可固定对象时打开选择器。
- 比 **V** 保持半秒打开菜单；张开手，把光标停在按钮上选择或翻页。菜单每页顶部都有“自动拾取／手动选择”，也可用手势停留切换。
- 树、山、船、鸟、花、云可逐个移动；菜单还可调整环境、数量与图层，或捏合画落叶路线。
- 用 **V → 编辑对象**复制、剪切、粘贴、复制一份、删除、撤销或重做；每页快捷栏可直接复制、粘贴、删除。

选择粘贴后，副本跟随手掌预览，捏合并松开才放下；丢手或 `Esc` 取消。复制保留当时的造型和大小，删掉原对象后仍可粘贴。复制、剪切与删除支持树、山、船、鸟，使用当前实验页的内部剪贴板。

无需鼠标切换对象。支持手势撤销、恢复、音乐和沉浸画布；真正的浏览器全屏用按钮或 `F`。键盘：`T` 切模式、`V` 菜单、`A` 自动拾取、`L` 画路线、空格暂停、`R` 恢复、`M` 音乐、`⌘/Ctrl+Z` 撤销。对象编辑：`⌘/Ctrl+C / X / V / D` 复制／剪切／粘贴／复制一份，`Delete` 删除，`⌘/Ctrl+Shift+Z` 重做。

首次可能下载约 10 MB 识别文件，之后通常复用本机缓存；每次仍需初始化识别。相机画面只在本机处理，不上传。独立的 `/gesture/` 实验页保留逐朵花、逐片云和图层移动、复制外观快照等本机玩法；这些额外实验数据不写入首页共享房间。

## 本地运行

需要 Node.js 24 和 npm，在项目目录执行：

```sh
npm ci
npm run build

PUBLIC_ORIGIN=http://127.0.0.1:4328 \
DATABASE_PATH=/tmp/teamlink-local.sqlite \
ROOM_IP_SALT=local-demo-only-change-for-deploy \
PORT=4328 npm run preview
```

打开 <http://127.0.0.1:4328>。以上配置仅供本地开发；运行测试使用 `npm test`。

豆包对话需在启动前设置服务端环境变量 `CLAW_API_KEY`；未设置时可手动编辑和使用基础调景指令。部署与环境配置见[部署说明](deploy/README.md)。

## 使用说明

- 共创房间约每 1–2 秒同步，链接有效 6 小时；持有链接的人可以读取和修改房间。
- 共创风景及消息保存在服务端。发送对话时，当前消息和场景参数会经 ClawHunt 发送给豆包；请使用演示内容。
- 对话用于调整已有的风景元素。本项目使用独立演示数据，未接入真实团队资料。
