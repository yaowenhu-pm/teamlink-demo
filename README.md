# TeamLink · 一起动手想

[共享风景入口](https://teamlink.yaowenhu.cn/) · [GitHub Pages 入口](https://yaowenhu.cn/teamlink-demo/)

直接拖动太阳、点击树木调整枝形，一笔画出落叶路线，或者对风景说一句话。扫码后，手机与大屏连接同一个房间；修改由服务端保存，其他设备约每 1–2 秒轮询同步。无需安装或登录。

## 先试一次

1. 打开风景，点一下画布后按 R，边画边看叶子跟随笔尖，松手保存新路线；也可以直接拖动太阳。
2. 扫描风景旁默认展示的二维码，手机会进入当前房间；点击二维码可放大。
3. 在手机上说“下点小雨”或“树再多一些，风轻一点”，核对消息结果和大屏变化。
4. 使用撤销恢复最近一次场景修改。遇到版本冲突，先查看最新状态，再重新确认操作。

可直接说“增加两艘船，多两座山，把树全部移除”，也可接着说“船少一艘，山少一座”或“鸟改成五只”。船和山各支持 0–8 个，鸟支持 0–20 只，树和花各支持 0–100 个；数值为 0 时全部移除。明确数量超出范围时不应用修改。

也可以直接点选并拖动树、山、船、鸟。船支持画布内复制、粘贴，或用 ⌘/Ctrl+C、V；原船位置保留，新船出现在旁边。“再来一个”或 ⌘/Ctrl+D 可添加同类对象，删除后可撤销。所有修改使用同一份参数、共享和撤销协议；原来的太阳拖动、点击树打开枝形、落叶回放、外部滑杆、文字对话和 JSON 编辑继续保留。

手绘路线支持 S 形、转圈和逆行。画线时单片叶子和参数即时预览，松手后才提交同一房间，整笔可一次撤销；Esc 或绘制中的 ⌘/Ctrl+Z 取消当前笔并恢复原路线。也可拖动起点、终点，或恢复默认随风路线。回放进度独立于环境运动，拖动回放点只影响本机查看。水纹、太阳、鸟和船持续运动，但不会自行改写 `hour` 等场景参数。全局暂停会停住环境与这片叶子，仅在本机生效，不改变共享场景；暂停时仍可选择和复制船。

画布内按 `?` 或点工具条的 `?` 查看完整快捷键：R 手绘、Space 播放／暂停、M 音乐、F 全屏、⌘/Ctrl+Z 撤销、⌘/Ctrl+C/V/D 复制／粘贴／再来一个、Delete 删除、方向键微调（Shift 加大步长）。输入框、参数编辑、中文输入法组合和弹窗保留正常键盘行为；普通画布快捷键只在画布激活且可见时接管。

风景音乐保留原 v1 的同一旋律，通过音乐按钮开启或关闭；开启后，在浏览器原生全屏里也会循环播放。关闭选择会被尊重，不因进入全屏而重新开启。音乐和全局动画暂停分别控制，均为本机状态。

展示时点击风景右上角“全屏展示风景”，或在非输入状态按 F。页头、代码、二维码和对话框收起，画布内的拖动、复制、枝形面板和轨迹调整仍可用；手机也可修改同一个房间。按 Esc 或移动鼠标后点击退出返回工作台。浏览器不支持或拒绝全屏时，仅铺满网页并明确提示。

右侧提供真实参数、前后对比与渲染源码。编辑 JSON 参数会即时预览，点击“应用并同步”才提交到共享房间；取消可恢复。拖动太阳或调整树形也会更新同一份参数。渲染源码读取本站实际模块，只读展示；参数输入不执行 JavaScript。手机可展开代码，并在编辑区上方查看同参数的小预览。

新版首屏短片 v3 使用新的单叶手绘、船复制与拖动实录，配回原音乐前 15 秒，已上线 [`/media/teamlink-intro-v3.mp4`](https://teamlink.yaowenhu.cn/media/teamlink-intro-v3.mp4)。15 秒／24fps／1280×720 成片已完成解码、画面检查和国内站冷加载自动播放验证；v1/v2 保留历史版本。首屏仍在房间连接后自动循环播放，可用原生控件调声音、暂停或全屏。滚出画面或切换到后台时暂停，主动暂停后不会擅自续播；浏览器阻止自动播放时保留海报和播放控件。影片与独立的 30 秒原曲均由同源 `media/` 提供。

对话通过 ClawHunt 接口调用豆包，默认模型为 `doubao-seed-2.1-lite`。模型提出参数修改，服务器校验字段、范围和当前版本后才应用。当前支持时间、树木/花朵/帆船/山峰数量、风雨、树枝形态及场景排列；不会任意生成或执行代码。未配置模型时明确显示有限调景指令模式。

## 数据与共享边界

- **发送对话时，当前这条消息和当前场景参数会经服务器发送到 ClawHunt，由其提供豆包解释服务。** 房间场景、消息和撤销快照保存在阿里云服务器的 SQLite，持有编辑链接的人可以读取和修改。
- 房间链接包含随机访问凭证，有效期 6 小时；过期后拒绝读写，过期记录随后有界清理。链接代表访问能力，消息不代表经过认证的成员身份。
- 同一房间没有累计编辑次数或单房间对话次数上限；近期消息滚动保留 64 条，撤销保留最近 15 次。全站每天最多 200 次模型请求，失败调用也可能占用额度；这项全站预算不限制直接编辑。旧操作的请求编号保留到房间到期，重放不会重复调用模型或再次修改，冲突不会静默覆盖其他端的修改。
- 演示从独立的虚构风景开始，不接入私人 `team-relay` 数据、个人 Codex、真实飞书或 GitHub 写入。请使用适合房间参与者和第三方服务接收的内容。
- `CLAW_API_KEY` 和 `ROOM_IP_SALT` 仅由维护者配置在服务端。创建限流保存按小时加盐的 IP 摘要，不保存原始 IP；密钥不得放入网页、二维码、源码或导出文件。

原官网和导出工作区保留在 `/legacy/`、`/legacy/app/`。旧作品链接与原本浏览器存储继续兼容；历史导出工作区使用副本分享，与当前共享房间的同步机制不同。

## 本地开发

使用 Node.js 24 和 npm。维护者先配置未跟踪的本地服务端环境键：`CLAW_API_KEY`、`ROOM_IP_SALT`；模型可选项为 `CLAW_MODEL`，接口地址限制为 ClawHunt。

```sh
npm ci
npm test
npm run build
export PUBLIC_ORIGIN=http://127.0.0.1:4328
export DATABASE_PATH=/tmp/teamlink-local.sqlite
export PORT=4328
# 从本机安全环境加载 CLAW_API_KEY 与 ROOM_IP_SALT 后运行：
npm run preview
```

打开 [本地预览](http://127.0.0.1:4328)。启动时应用版本化迁移，本地数据库与生产数据库分离。自托管部署、备份和回退见 [部署说明](deploy/README.md)，不需要 Sites 项目身份。

- `web/`：风景页面、交互、绘制与场景模型；`web/legacy/` 保留历史体验。
- `worker/`：可复用房间 API、ClawHunt 适配器；`server/`：Node HTTP、SQLite、静态媒体与一致性备份。
- `db/schema.ts`、`drizzle/`：SQLite 表结构与版本化迁移；改结构后运行 `npm run db:generate`。
- `build/public/`：生成的浏览器代码和同源媒体；`build:sites` 保留旧 Worker 的构建兼容。

CI 检查语法、全部模型/房间/适配器测试及构建，不需要真实密钥、不调用真实模型或执行部署。实际线上模型连接、实体扫码和手机双端 UI 仍需发布后分别验收；自动检查不代表这些链路已通过。

直接操作和可见过程参考 Bret Victor 的 [Inventing on Principle](https://worrydream.com/InventingOnPrinciple/)、[Learnable Programming](https://worrydream.com/LearnableProgramming/) 与 [Explorable Explanations](https://worrydream.com/ExplorableExplanations/)。
