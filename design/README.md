# TeamLink 设计稿

官网以 `website-home.svg` / `website-home.png` 为可编辑概念稿，运行页面位于 `dist/index.html`。主标题为“一起改作品，把想法变清楚”，首屏使用真实可修改的产品片段，后续介绍工作过程、工具角色与体验入口。实际前端将交互片段放在首屏右侧，响应式布局以网页为准。


当前实现以 `gatherthread-v3.svg` / `gatherthread-v3.png` 为方向：中央直接编辑作品与规则，结果紧邻作品；右侧保留项目目标、命名方案、批注和显式 Agent 交接。设计稿为可编辑文字与矢量节点，运行行为以实际网页为准。

`canvas-v2` 保留上一版直接操作设计；`desktop-core` / `mobile-core` 为更早的顺序交接稿，已不代表现行体验。

Figma Starter 工具调用额度此前已耗尽，本轮使用仓库内可编辑 SVG，没有新增 Figma 节点。
