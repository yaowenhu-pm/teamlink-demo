# 一片可以一起改变的风景

打开就是世界。桌面拖动太阳或说一句话，手机扫码后控制同一个世界；景色立即响应，改动可以撤销。主界面不放营销标题、表单、任务步骤或属性面板。

## 最小范围

一个固定 seed 的海岛湾。首版只改变时间、树木密度、雨量和风；画面保留可辨认的山形、海岸和原有树木位置。用同一份世界状态驱动桌面与手机，不用替换两张预制图片冒充修改。

| 用户动作 | 参数变化 | 同时发生的可见结果 |
| --- | --- | --- |
| 拖太阳／“把夕阳变成夜晚” | `timeOfDay` | 天色、太阳／月亮位置、海面反光与星光一起变化 |
| “多一些树” | `treeDensity + 0.2` | 同 seed 的候选位置逐步出现树；已有树不跳位置 |
| “让雨停” | `rainIntensity → 0` | 雨线消退，水面雨纹随后缓慢消退 |
| “风再小一点” | `wind` 降低 | 云、水波和帆船摆动一起变缓 |

明确句型可直接映射参数，无需假装实时大模型生成场景。暂不支持的表达，简短说明当前能改什么；不播放“正在生成”后换一张无关背景。

## 直接操作

太阳本身就是时间控制器。靠近或触摸时才出现轻轨迹与时刻；拖动过程中连续改变光线，不等松手或点击确认。一次拖拽记成一次可撤销改动。

桌面底部只有一句话输入和少量可点的建议。手机保留世界预览、输入、最近一句话与结果 chip，例如“多一些树”→“树木增加 20% · 撤销”。有效命令发送后直接修改；不用先生成任务或审批。chip 描述实际变动，不模拟有人或 Agent 在线回答。

日夜与天气使用短插值过渡，输入过程中始终可以继续操作，不用等待动画结束。水波、薄云与帆船保持轻微运动，主要注意力仍在景色。

## 主视觉与连接

采用克制的程序化 2D 风景：低太阳、青绿山岛、深蓝海湾、纸雕感松林和一只小帆船。远景降低对比，近景加深；反光由柔和光晕与水纹组成，不画硬边光柱。SVG 保留独立矢量、文字和分组，没有位图背景。

“手机控制”打开当前房间的真实连接二维码。手机必须确认连接到该房间后才显示“已连接”；等待、断线与重新连接如实反馈。分享另一个独立副本不能称为控制同一世界。连接尚未实现时，桌面仍可本机操作，但不能显示假的手机联动。

首个验收动作：手机发送“让雨停”，桌面同一个房间的雨量状态及画面改变；桌面撤销后，两端回到同一状态。再验证拖太阳、日夜变化和树木增量。当前交付仅为设计概念，未改应用、未发布、未重试 Figma。
